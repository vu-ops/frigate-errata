Collection: Human + Machine Review keeps everything, Human Review Only keeps only events needing a human decision, Monitor Only (Ignore) still collects events but sends them straight to Ignored (never reviewed; purged after the ignore window). GenAI Description Search scans GenAI descriptions of new events for this label's synonyms (across all detector labels) and surfaces matches for review — use it to grow a new label. Include in Training decides whether a label is exported; disabled means collect-only. Auto-approve lets the analyzer confirm this label without a human. Include Auto Approved in Training allows coherent auto-approved events to be reused as training labels. Snapshot Limit caps how many auto-approved/ignored snapshots are kept per label (blank = default {{ global_keep }}, 0 = keep forever).
