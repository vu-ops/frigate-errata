Model deployment — Frigate
Activating a model saves a backup of the Frigate config, switches the model path via the Frigate API, and restarts Frigate (detection pauses for a few seconds). Reverting restores a previous config backup the same way.

Training
The Train button trains on the device configured in config.yaml (training.device; Intel Arc XPU by default) and falls back to CPU automatically if the GPU is unavailable. Prefer faster training? Download the Mac training kit (.zip) — it bundles the dataset, the source files, and a shell script to train on your Mac (see its README for Homebrew setup).
