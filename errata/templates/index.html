Each card shows a detection: the snapshot (click to enlarge), the YOLO label, confidence, why it was flagged, and the GenAI description. The quick buttons confirm the image as that label in one click — first is what YOLO detected, the rest are suggestions from the GenAI description. Use the dropdown + Change for any other label, False positive if there is nothing there (only when no other object of interest is in frame), or Skip to set it aside entirely. Corrections accumulate until the retrain threshold — see Summary for progress.
Review past decisions: use the View filter to show Corrected, False positive, Auto-confirmed, Ignored, or Skipped events. A corrected card shows the chosen label as → label; pick a different one and click Change to fix it, or Undo review to send the event back to the queue. Re-reviewing replaces the previous correction, so training always uses your latest decision.
Bulk change: the toolbar has two actions. Apply to matching sets a status on every pending event matching the Camera / Label / Reason filters (leave them at All for the whole queue; pick skipped to set aside all remaining items in one go). Apply label to matching re-labels every event in the current View matching the filters to the chosen label — e.g. View Corrected + Corrected-to fox + Set label coyote re-labels all fox corrections in one click. It replaces any existing correction on those events, so double-check the View and filters first.
